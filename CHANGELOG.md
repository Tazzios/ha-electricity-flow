# Changelog

All notable changes per version. Versions without a release were test versions on the
way to the next release.

## 0.10.2 - 2026-11-23

Your installation is converted automatically. Prices of older versions are removed:
set them again on the devices.

### Added
- The installation is built from devices, added one at a time with **Add device**:
  the grid (once), any number of solar sets and any number of batteries.
- A **House** device, created automatically, with the house costs.
- Per device a **Total** for today and this month:
  - Solar set: the value of all it delivered.
  - Battery: what it delivered minus what charging it cost, at the price of the
    source. It can go down.
  - Grid: what it delivered minus the energy fed back, at its price. It can go down.
- Option **Diagnostic sensors** (at setup and via **Configure**): only then the kWh per
  quarter sensors are created, as diagnostic sensors without long term statistics.
- A release now includes `electricity_flow.zip` for HACS.

### Changed
- Every price is set on the device that is the source of the flow (grid, solar set
  or battery). The House page is gone; the house cost is the sum of solar, grid and
  battery to home.
- Per quarter the flows are divided over the solar sets and batteries by each one's
  share of the production, charge or discharge.
- A solar set has one meter; a battery one charge and one discharge meter.
- Meter pickers only show energy sensors (Wh, kWh, MWh), price pickers only prices
  per energy.
- Price fields are labelled "Price – <flow>".
- Entity ids contain the name of the device, for example
  `sensor.ef_marstek_price_battery_home_day`.

### Removed
- The input sensors (measured kWh per meter) and the grid net sensor.
- Sensors that are no longer made are removed from Home Assistant.

### Fixed
- No more warnings about deprecated `via_device` and `async_get_device`.
- Works with the schema types of the newest Home Assistant.

## 0.8.0 - 2026-11-22

### Added
- Repair issues under **Settings → System → Repairs** when a sensor is selected
  for more than one role, a meter or price is unavailable for over an hour, a meter
  or price has an unsupported unit, or a price is in another currency than Home
  Assistant. They clear by themselves once fixed.
- Release workflow: a version tag creates the GitHub release.

## 0.7.0 - 2026-11-21

### Fixed
- Implausible meter jumps (more than 10 kWh per update) are ignored, so a meter that
  briefly reports 0 no longer books its whole reading in one quarter.
- Small decreases keep the old baseline (noise was counted twice).
- Meter resets are detected from the `last_reset` of the source (daily counters).
- Quarter sensors are rounded to 3 decimals.
- The state is saved on unload and reload, and removed with the integration.

### Changed
- New installations get entity ids generated by Home Assistant; existing ones keep
  theirs.
- Quarter attributes of the cost sensors are not recorded.
- Minimum Home Assistant version 2025.3.0.

### Added
- Checks on GitHub: hassfest, HACS validation, ruff, pytest and mypy.

## 0.6.0 - 2026-11-21

First version in this repository (moved from Tazzios/Home-Assistant), with a HACS
layout and MIT license.

- Energy flows per quarter between solar, battery, grid and home, without utility
  meters or template sensors.
- Cost sensors per flow for today and this month, with a price entity or a template
  per flow.
